## 1. 聚类：balanced 容量切片

### 1.1 机制（大白话版）

两段式：k-means 先把 116M 篇文档聚成 ~1000 个"细簇"（"微积分习题"粒度的小团）；再归组成 15 个"宏簇"供搜索使用（搜索在 15 维配比空间做，不能直接搜 1000 维）。

论文的归组方式（语义合并："数学的归数学"）在本池上结构性失效：嵌入空间是**一整块连续大陆，没有山川分界**，按相近合并链式反应，99% token 塌进一个巨簇（D14 实测：K=14/21/24/32 全留 97.5–99%）→ 搜索只剩 1 个旋钮，配比优化失去意义（prod1 死因）。

我们的方式 = **切地盘**（cluster_merge.py:917-1127）：
1. 在 L2 归一化的细簇质心空间撒 15 个"桩"（k-means++）；
2. 1000 个细簇按 token 降序排队，逐个加入**最近的、还有余量的**桩，cap = 总量/K×(1+slack)，slack=0.15 → 构造性保证最大簇份额 ≤8.8%；
3. 桩反复挪到成员的 token 加权中心（≤10 轮）至分组稳定。

结果：15 块大小相近、各自连续的领土。**容量上限强迫把大陆主体切开分掉**——这是平衡的硬保证所在；撒桩只负责切片地理连贯。

### 1.2 k-means++ 撒桩的理论地位

"让桩尽量分散"是直觉描述，严格保证是另一件事（Arthur & Vassilvitskii 2007）：后续桩按 D² 概率采样（D=到最近桩的距离）→ **期望意义下聚类代价 ≤ 8(ln k)+2 倍最优**。分散的机理：落在已有桩附近的概率 ∝ D²→0，概率质量集中在覆盖最差的区域。但这是随机的、期望性的——单次可能不走运；"最大化最小间距"（k-center）的确定性 2-近似要用最远点遍历（Gonzalez 1985），我们没用。

**关键澄清：平衡不靠撒桩。** 分工：

| 部件 | 职责 | 保证强度 |
|---|---|---|
| k-means++ 撒桩 | 锚点别挤一团（切片地理连贯） | 期望性近似，随机（seed=42 固定 → 单次运行确定性） |
| 容量上限 cap | 最大簇份额 ≤ (1+slack)/K | **构造性硬保证，与撒桩质量无关** |
| 加权锚点迭代 | 切片语义更紧凑 | 局部收敛 |

撒桩差 → 切片地理狭长、cosine 审计难看（balanced_profile.json 的 advice 标警告），但平衡不破。

### 1.3 业界依据

- **骨架有据**：容量约束分配内嵌 Lloyd 迭代 = **balanced k-means / size-constrained clustering** 家族标准形态（Malinen & Fränti 2014 等）；"token 降序 + 最近可用"= 运输问题/装箱 FFD 式经典启发式（**非全局最优**，最优是 min-cost flow）；OR 的 territory design（选区/配送区）同款"容量+邻近"规则；统计学分层抽样（strata）同思想。
- **应用无直接先例**：语料混合线上——CLIMB 用语义合并、DoReMi 等用域标签，无人把平衡容量切片当混合旋钮。这是被本池几何逼出的 bespoke 适配（D14），属于本项目的应用层创新。
- 定位一句话：**成熟机制 + 我们的应用适配**，不是业界标准做法的搬运。

### 1.4 锚点最优性与换池稳健性

**最优性：正确地没有保证。** 管线中没有任何环节直接优化"对搜索的区分度"——撒桩优化覆盖代价、迭代做局部精化、cap 管平衡；**"哪个轴对模型训练有价值"唯一能发现它的机制是搜索本身**。系统哲学 = 生成足够丰富的通用基底（15 个平衡、地理连贯的切片），让搜索在基底上表达价值，而不是先找"正确的特征"。prod4 证据：赢家 = C10+C5 两切片 + 12 地板——基底表达力足够。

**换池不会"旧桩套新池"**：锚点每次从当前池的细簇质心重算（嵌入/聚类缓存按池内容哈希键控，pool_embedding_cache_key）。真正的风险三个，全部离线可检：

1. **seed 运气**：单次 k-means++ 抽签在新池上可能不走运——未测量。对策 = 多 seed 稳定性研究（§1.8）；
2. **策略错配**：新池若是多岛结构（如论文 800B 通用语料有真实主题分界），语义合并可能复活、balanced 反而过度切割。对策 = **换池第一步跑几何诊断**（fixed-K distance 扫描 + 份额画像；D14 保留 distance 对照；衔接 prod4 设计指令⑦"换池先重跑池表"）；
3. **K 错配**：15 = 论文 D.4（他们的池+112 点预算）+ 我们预算的产物，新池自然粒度可能不同。对策 = K-sweep（§1.8）。

### 1.5 为什么生效：三层分析

1. **对手是退化解（门槛对比）**：distance 合并在某些 (K,τ) 下塌成巨簇——真实对比不是"平衡 vs 理想语义聚类"，而是"平衡 vs 塌缩"。任何 15 旋钮的质量均衡划分都赢 1 旋钮。
2. **信号是区域性的，不是主题性的（最有解释力）**：连续流形上容量切片 ≈ 沿主变异方向切割。赢家两个引擎切片有极强的功能性差异——C10（α=.474，~389 tok/doc，短题类）vs C5（α=.354，~2180 tok/doc，长文献类）——切出来的是**文档功能类型轴**（短题 vs 长参考），正是混合价值依赖的轴。原因：嵌入空间本身按功能类型组织文档（短题与短题天然靠近），沿自然纹理下刀就切出这种分区。搜索需要的是**可区分的方向**，不是纯净的主题（cluster_merge.py:950 注释、D14:243）。
3. **稀释低于搜索分辨率（假设，可检验）**：切片是混合物 → "调 C10 到 0.47"吃进的是那块领土的全部内容，纯净化收益差距 = 稀释损失。但搜索只实测 111 个配方、15 维空间稀疏——只能定位"哪片区域好"，定位不了"区域内哪个点最好"（天花板证据：proxy online ρ≈0.42–0.58、d20→d28 排名翻转、种子带 ±0.016–0.032）。若稀释损失只有千分之几，埋在噪声地板（§3）下面——搜索既发现不了也利用不了。**可证伪**：§1.8 的 K-sweep 若显示更细切片让最佳配方分数系统性上升 → 稀释真实且可利用；不动 → 低于分辨率。

### 1.6 F 类具名发现（可迁移设计知识）

**F1 功能轴假说（高价值）**：对模型训练有效的混合轴是**文档功能类型**（题集/文献/词典…），不是主题、更不是人的域标签——没人标注过它，无监督容量切片沿嵌入空间的自然纹理下刀恰好切出了它。
- 证据链：① L1b 判决——domainfix 臂（人的四域配比、数学 60%）落 uniform 带，簇级配比赢（experiment_prod4.md §5）；② 赢家引擎切片的功能对比——C10 389 tok/doc vs C5 2180 tok/doc（§3e 簇表）；③ D14:243 原则行（"搜索需要的是可区分，不是纯净"）。
- 可证伪面：换池后语义簇显著优于容量切片（K-sweep 对照），或赢家权重不可按功能解释 → 假说弱化。
- 迁移含义：换池时不必寻找"正确的分类学"——先保证基底平衡可区分，让搜索发现价值轴。

**F2 可区分旋钮原则**：混合搜索的聚类层目标 = 提供可区分、质量均衡的剂量旋钮，不是复刻人类分类。失败态两头：塌缩（1 旋钮，prod1）与过碎（超出搜索分辨率）。平衡点由**池几何 × 搜索预算**共同决定（预算 111 点 ↔ K=15 在论文侧的对应是 112 点 ↔ K=21）。

### 1.7 离线实验计划（零训练，池级缓存上做）

| 实验 | 设计 | 回答 |
|---|---|---|
| K-sweep | K∈{10,15,20,25} 重聚类，切片画像对比 + 赢家权重跨划分转移性 | 1.5-层3 的稀释假设；K 是否该调 |
| 多 seed 稳定性 | seeds∈{42,1,2,3} 重跑 balanced，比较划分重叠度/份额/cosine | seed 运气风险（1.4-①） |
| 池几何诊断规程化 | fixed-K distance 扫描 + 份额画像的脚本化 | 换池第一步：选 merge 策略 |

### 1.8 结论与预判

balanced **不是当前瓶颈**——prod4 证明瓶颈在选择机制（热区真实 + 外推死，§2）。聚类改进是二阶项：建议下轮保持 balanced+K=15，工程预算投给 P1；离线三实验在换池前执行。

### 2.2 三个静态发现

**① 特征重要性的"C5 分歧"可能被夸大（诊断 artifact）**：报告用 **split counts**（分裂次数）——度量"特征被用几次"，不是"响应斜率多大"。C5 仅 2.4% splits ≠ predictor 对 C5 大权重无响应。需 gain/SHAP 重打分才能定论——直接改变"赢家外推缺乏支撑"证据条的强度。

**② 固定 20% 验证集 = 训练税**：每次 refit 用 rng(42) 切 20% 供早停/R²（:425-435），终轮模型只见 89/111 点。小 N 下大税；标准做法 = **早停定轮数后全量重拟合终模型**，白捡 22 点。论文只说验证集服务早停，未规定终模型训法——改它不违背论文。

**③ D3 旧决策已被 prod4 推翻**：D3 记录 2026-09-10 曾否决"argmin 与最佳实测比较"、仍按论文 argmax。之后证据到位：L1a（两个实测点胜过外推赢家）+ 赢家邻域实测 1.05–1.13 全低于最佳实测 0.12–0.40（赢家诅咒签名）+ 08-29 smoke_search 合成证据（argmin 落后 best-measured 0.2–0.3 utility）。**P1 正当性链完整**。

### 2.3 P1 设计：best-measured 终选 + no-claim 守卫

- **改动点**：`_select_final_mixture` 正常路径（:1130-1131）——计算 best-measured；跑设计空间 argmin（现状保留为对照）；**argmin 对 best-measured 的预测优势 < margin → 选 best-measured，selection_mode="best_measured_no_claim"**；否则允许外推但记录半径+邻域证据进 claim 报告。
- **margin 定标**：held-out 残差 σ（predictor_eval 的 40 对 (pred,actual)）× 系数——待服务器数据拉取后定。
- **复测已被否决（用户裁决 2026-09-20）**：轮次 1–3 本身就在实测配置，单点复测 = 整轮排队成本换 1 个测量，投入产出不成正比；且 best-measured 构造性地消除了复测要验证的对象（终选永远是已实测点）。
- 衔接 prod4 指令② 前半：top-k 实测点直接进臂验证（搜索输出按**区域**消费）。

### 2.5 改进提案分级

- **P1（已裁决，本轮实现）**：best-measured 终选 + no-claim 守卫。
- **P2 候选**：① 早停后全量重拟合（发现②，低风险白捡 20% 训练点）；② LightGBM 种子集成（5 seeds → 均值+方差 → LCB 获取与 no-claim margin 直接受益）= prod4 指令②"不确定度感知获取"的落地形态。
- **不动项**：verbatim 采样（D2 有数值证据：扰动被证伪）、剪枝语义（论文 §2.2 对齐；修的对象是终选不是剪枝）。
- **论文参考边界**：超参/采样/剪枝语义论文有明文且已对齐；全量重拟合论文语焉不详（可改）；集成/LCB 与 best-measured 守卫论文完全没讨论——后者是我们在推翻论文做法（带着 L1a 证据）。论文 D.10 的 94% Spearman 不可作目标（他们 3 个 MC 验证损失 vs 我们 6 任务含生成 CoT，标签噪声不同源）。

## 3. 术语：噪声地板

**测量自带的随机波动幅度——比它小的差异与随机抖动无法区分。** 任何 A vs B 的差距小于地板，单次测量无法裁决：要么接受不确定、要么种子对、要么加 N。这就是 prod4 gap 报成带、热区内排序软（互差在地板下）的原因。

| 噪声源 | 幅度（本项目实测） |
|---|---|
| 训练种子 | ±0.016–0.032 STEM（prod4 T1 种子带）——最大成分 |
| 基准抽样 | 单任务 ±0.05–0.07（gpqa N=198，1 题 = 0.5pp） |
| proxy 排名 | online ρ≈0.42–0.58 |
| eval 批数值 | ±1 题 ≈ 0.0008（b16 代际，D18） |

形式化（二项噪声/SNR 加权）见 scoring_metric_design.md §5。
