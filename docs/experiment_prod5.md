**V2 最好结果归属与跨轮提升（用户核心目标）**
- top-1 d28 臂是否为 CLIMB 候选？
- top-1 vs top-2 CLIMB 候选差距 vs 种子带 → 加冕按 P-2 规则表述。
- **跨轮提升**：prod5 top-1 vs prod4 top-1（cfg72 **0.2142** / cfg25 0.2066）——同预算/同池/同聚类缓存下，优化后算法找到的最终答案是否更好；差距落在种子带（±0.016–0.032）内 → 如实报"并列量级"。注意：本轮配置全新采样，跨轮差**不是** D19 的受控消融——提升按通道记账，不按总分记账。
- **提升通道账**（判决区回填）：① no-claim 守卫 = 地板保护（prod4 反例：终选 0.1972 输自家实测 cfg72 0.2142，守卫可免——本轮守卫触发即兑现此通道）；② top-3 臂 = 3 次实测候选射门（prod4 为 2 次：cfg25/cfg72）；③ A2 全量重拟合 = 后轮候选生成 + 放行时 argmin 的质量（prod4 反例：argmin 实现敏感、外推赢家 claimed gain −0.47）。若跨轮无提升 → 按通道定位失效腿。

## P-2 gap 报告与加冕规则（预注册）

- **误差带口径**：基线单种子 → gap 引用 prod4 实测种子带作历史参考（random 0.1647/0.1833，带上沿 **0.1833**；训练种子带 ±0.016–0.032 为最大噪声成分；同池同 3B 预算下成立）。记分板随附逐任务二项 SE 表。
- **判读优先级**（指令⑥）：大 N / 可复现列优先（gsm8k N=1319 双种子位逐位可复现；gpqa N=198 单种子摆动 ±.03–.07 已知）；复合分小 N 噪声由本规则承担，不动评分公式（见 P-3）。
- **加冕规则**：top-1 vs top-2 CLIMB 候选差距 < 0.016–0.032（种子带）→ 报带 + 按分高加冕 + 标注"统计并列"；不补 rep（全员单种子，公平性裁决）。
- **"明确领先"的表述口径**：高于 uniform 带上沿且逐任务方向一致 = 强；仅复合分领先且差距在带内 = 弱（如实报）。
